# 💸 Expense Tracker в Telegram

Трекер личных расходов, который живёт в Telegram. Запись траты — одно сообщение боту:

- `кофе 350` → ☕ Кофе, 350, категория «Кафе»
- `такси 900 работа` → 🚕 Такси, 900, категория «Работа»
- `$12 обед`, `обед 450р`, `1 200 магазин` — несколько валют тоже понимаем

Второй компонент — **веб-панель**: расходы по дням и категориям, итоги за сегодня / неделю / месяц. Вход — через того же бота, без паролей.

## ⚡ Путь судьи за 60 секунд

1. Открыть бота → `/start`.
2. Написать `кофе 350` → бот отвечает `✅ #1 ☕ Кофе — 350 TJS`.
3. Написать `/app` → открыть ссылку → в панели уже виден график и эта трата.

## 🧱 Как устроено

Один Node.js-сервис (без сборки фронтенда и без нативных зависимостей):

- `src/index.js` — точка входа: HTTP-сервер + бот (polling или webhook).
- `src/bot.js` — Telegraf: приём трат, итоги, правка/удаление кнопками, лимиты, пары, `/export`, `/sheets`, `/app`.
- `src/parse.js` — парсер «сумма + описание + категория», чистка слов-паразитов, split нескольких трат, поиск итога в OCR-тексте чека.
- `src/categories.js` — 10 категорий с русскими алиасами и ключевыми словами.
- `src/store.js` — выбор хранилища: Postgres (`DATABASE_URL`, вечное хранение) или SQLite-файл (локально).
- `src/db.js` — SQLite через встроенный `node:sqlite` (файл `DATA_DIR/expenses.db`).
- `src/pgstore.js` — тот же API поверх PostgreSQL (Vercel Postgres / Neon).
- `src/sheets.js` — выписка в Google Sheets через сервисный аккаунт.
- `src/auth.js` — вход через Telegram: magic-ссылка из бота, WebApp `initData`, Login Widget; сессии — JWT.
- `src/server.js` — REST API + раздача `public/`.
- `public/` — Mini App на чистом JS: таббар (Главная/Статистика/История/Ещё), графики на canvas, нативная тема Telegram, MainButton/BackButton, haptics.

## 🚀 Запуск локально

Требования: **Node.js 22+**, ничего больше ставить не нужно.

```bash
npm install
cp .env.example .env   # Windows: copy .env.example .env
# заполнить BOT_TOKEN, JWT_SECRET, PUBLIC_URL
npm start
```

Панель: http://localhost:3000. Бот: polling по умолчанию.

Быстрая проверка без Telegram (только для локальной отладки):

```bash
# .env: ALLOW_DEV_AUTH=true, BOT_TOKEN=dummy
npm test   # парсер + API (изоляция пользователей, CRUD, статистика)
```

## 🔑 Переменные окружения

| Переменная | Обязат. | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен от [@BotFather](https://t.me/BotFather). В репозиторий не коммитить! |
| `JWT_SECRET` | да | Любая длинная случайная строка для сессий панели |
| `PUBLIC_URL` | да | Публичный URL панели, напр. `https://expenses.example.com` (нужен для кнопки `/app`) |
| `BOT_USERNAME` | для Login Widget | Username бота без `@` (включает вход через виджет на панели) |
| `PORT` | нет | По умолчанию `3000` |
| `DATA_DIR` | нет | Каталог SQLite-файла (по умолчанию `./data`) |
| `BASE_CURRENCY` | нет | Базовая валюта итогов (по умолчанию `TJS`) |
| `DEFAULT_CURRENCY` | нет | Валюта, когда пользователь её не указал (по умолчанию = `BASE_CURRENCY`) |
| `RATES_JSON` | нет | Курсы к базовой валюте, напр. `{"USD":10.9,"EUR":11.8,"RUB":0.12,"TJS":1}` |
| `TIMEZONE` | нет | Часовой пояс для границ дней (по умолчанию `Asia/Dushanbe`) |
| `BOT_MODE` | нет | `polling` (по умолчанию) или `webhook` |
| `WEBHOOK_URL` / `WEBHOOK_PATH` | для webhook | Публичный URL + секретный путь |
| `OCR_MODE` | нет | `caption` (сумма из подписи к фото) или `tesseract` (OCR чека: ищет ИТОГО, иначе максимум) |
| `DATABASE_URL` | на Vercel — да | Строка подключения Postgres (Vercel Postgres/Neon). Без неё — эфемерный SQLite в `/tmp` |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | для Sheets | JSON-ключ сервисного аккаунта одной строкой |
| `GOOGLE_SHEET_ID` | для Sheets | ID таблицы (из URL); таблицу расшарить на email сервисного аккаунта |
| `GOOGLE_SHEET_RANGE` | нет | Куда писать, по умолчанию `A1` (можно `Траты!A1`) |
| `ALLOW_DEV_AUTH` | нет | `true` только для локальных тестов, на проде не включать |

## 🤖 Настройка бота (5 минут)

1. [@BotFather](https://t.me/BotFather) → `/newbot` → забрать токен в `BOT_TOKEN`.
2. `/setcommands` для бота:
   ```
   today - итог за сегодня
   week - итог за неделю
   month - итог за месяц
   list - последние траты
   edit - исправить трату
   del - удалить трату
   limit - лимит на категорию
   limits - показать лимиты
   export - выгрузить CSV
   sheets - выписка в Google Sheets
   pair - общий бюджет на двоих
   shared - общий итог на двоих
   app - ссылка на веб-панель
   ```
3. Задеплоить (ниже) с `PUBLIC_URL` на публичный домен, запустить — бот в polling-режиме всё подхватит сам.
4. Для Login Widget на панели: в BotFather `/setdomain` → домен панели, `BOT_USERNAME` — в окружение.

## 🌍 Деплой

**Render (free):** репозиторий уже содержит `render.yaml` — New → Blueprint, задать `BOT_TOKEN`, `JWT_SECRET`, `PUBLIC_URL`.

**Docker (любой хостинг):**

```bash
docker build -t expense-tracker .
docker run -p 3000:3000 --env-file .env -v exp-data:/app/data expense-tracker
```

**Vercel:** проект готов к деплою из коробки (`api/index.js` + `vercel.json`, бот в webhook-режиме).

```bash
vercel          # preview-деплой
vercel --prod   # продакшен
```

Затем в dashboard проекта (Settings → Environment Variables) задать:
`BOT_TOKEN`, `JWT_SECRET`, `PUBLIC_URL=https://<ваш-домен>.vercel.app`,
`BASE_CURRENCY=TJS`, `DEFAULT_CURRENCY=TJS`, `RATES_JSON={"USD":10.9,"EUR":11.8,"RUB":0.12,"TJS":1}`,
`TIMEZONE=Asia/Dushanbe`, `BOT_USERNAME=<username_бота>`.
Webhook на Telegram ставится автоматически при первом запросе. После смены env vars сделайте redeploy.

**Хранение данных на Vercel (обязательно, иначе данные исчезают!):**
Serverless без диска — SQLite в `/tmp` сбрасывается. Подключите Postgres:
Vercel dashboard → Storage → Create Database → Postgres → Connect к проекту.
Vercel сам добавит `POSTGRES_*` переменные — приложение подхватит их автоматически
(`POSTGRES_PRISMA_URL`/`POSTGRES_URL`/`DATABASE_URL`). Проверить можно в панели:
вкладка «Ещё» → «Хранилище: облачная база». Без базы там будет «локальный файл».

**Webhook-режим** (если хостинг не держит долгие соединения): `BOT_MODE=webhook`, `WEBHOOK_URL=https://…`, `WEBHOOK_PATH=/tg-webhook/secret`.

## 📱 Бот и мини-приложение

Весь интерфейс живёт в **Telegram Mini App**: кнопка «📱 Открыть расходы» под полем ввода открывает панель прямо в Telegram — с нативной темой, тактильным откликом, кнопками Сохранить/Назад и подтверждением закрытия при несохранённом тексте. Высота регулируется через Web Apps API (`expand()`, отслеживается `isExpanded`/`viewportChanged`).

Бот остаётся быстрым вводом — любое сообщение:

- `кофе 350`, `такси 900 работа`, `$12 обед`
- `потратил 500 на такси` — слова-паразиты вычищаются сами
- `кофе 350 и такси 900` — несколько трат одним сообщением
- вопросы: `сколько потратил?`, `итог за неделю`, `последние`

Под каждой записью: ✏️ Изменить · ↩️ Отменить · 🗑 Удалить. Команды: `/today` · `/week` · `/month` · `/list` · `/undo` · `/edit <id> <текст>` · `/del <id>` · `/limit` · `/export` · `/sheets`.

**👥 Общий бюджет на двоих:** один вводит `/pair` и получает код на 15 минут, второй вводит `/pair КОД` — готово. `/shared` показывает общий итог месяца (кто сколько + по категориям). В панели вкладка «Ещё» → «Общий бюджет»: код, привязка, общий итог. Расформировать: `/unpair`.

**🧾 Чеки:** фото чека с подписью-суммой («обед 450») записывается сразу; с `OCR_MODE=tesseract` сумма ищется в самом фото (строка ИТОГО, иначе максимум).

**📤 Google Sheets:** `/sheets` в боте или «В Google Sheets» во вкладке «Ещё» — выписка за месяц дописывается в таблицу. Нужны `GOOGLE_SERVICE_ACCOUNT_JSON` + `GOOGLE_SHEET_ID` (таблицу расшарить на email сервисного аккаунта с правом Editor).

**Привязка Mini App в BotFather** (опционально, синяя кнопка слева от ввода):
BotFather → ваш бот → Menu Button → указать `PUBLIC_URL`. Кнопка-клавиатура `web_app` работает и без этого.

## ✅ Бонусные фичи (все сделаны)

- Распознавание сумм из фото чека (подпись + OCR-режим с поиском ИТОГО).
- Несколько валют (`$`, `€`, `₽`, `руб`, `сомони`, коды USD/EUR/RUB/TJS) с конвертацией в базовую.
- Экспорт в CSV (бот + панель, с BOM для Excel) и выписка в Google Sheets.
- Общие бюджеты на двоих (`/pair`, `/shared`, карточка в панели).
- Лимиты по категориям: `/limit кафе 5000`, предупреждение в боте на 80% и при превышении, прогресс лимитов в панели.

## 🔒 Приватность

Каждая трата привязана к `telegram_id`; все запросы (бот и API) фильтруются по нему — чужие траты увидеть нельзя. В паре партнёр видит только общие итоги, но не отдельные записи друг друга. Секреты только в переменных окружения, в репозитории их нет (см. `.gitignore`).
